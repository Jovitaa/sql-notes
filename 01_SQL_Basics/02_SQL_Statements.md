# SQL Statements

## 📌 What are SQL Statements?
SQL statements are commands used to interact with databases.

## 🧠 Common SQL Statements
- SELECT → Retrieve data
- INSERT → Add new data
- UPDATE → Modify data
- DELETE → Remove data
- CREATE → Create database/table
- ALTER → Modify structure
- DROP → Delete objects

## ⚡ Syntax Example
SELECT column1, column2
FROM table_name;

## ⚠️ Important Notes
- SQL is NOT case sensitive
- Some databases require semicolon (;) at end
