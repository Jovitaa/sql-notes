# SQL Clauses

## 📌 What is a Clause?
A clause is used to define conditions or modify SQL queries.

## 🔹 WHERE Clause
Used to filter data

SELECT * 
FROM Employees
WHERE Salary > 50000;

## 🔹 ORDER BY Clause
Used to sort data

SELECT * 
FROM Employees
ORDER BY Salary DESC;

## 🧠 Key Points
- WHERE filters rows
- ORDER BY sorts results
- ASC is default sorting
