# SQL Introduction

## 📌 What is SQL?
SQL (Structured Query Language) is used to access and manipulate databases.

## 🎯 What can SQL do?
- Retrieve data
- Insert records
- Update records
- Delete records
- Create databases and tables
- Create views and stored procedures

## 🧠 Key Concepts
- SQL works with databases (RDBMS)
- Data is stored in tables (rows & columns)
- SQL is a standard language (ANSI/ISO)

## ⚠️ Important Notes
- Different databases (MySQL, SQL Server) have slight differences
- Core commands remain the same

## 🗂️ RDBMS
- Relational Database Management System
- Examples:
  - MySQL
  - SQL Server
  - Oracle
